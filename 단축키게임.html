미션 1 : 필수 기초

마법의 주문을 복사해서 금고에 넣기!

메모장에 적힌 글씨를 마우스로 드래그(선택)한 뒤 Ctrl + C 로 복사하고, 금고 입력창에 Ctrl + V 로 붙여넣으세요!

마법의 메모장 Ctrl+C 대상

아래 노란색 글씨를 마우스로 쭉 끌어서(드래그) 파랗게 만든 후 Ctrl + C 를 누르세요!

마우스를 드래그하여 글자를 파랗게 블록 지정하세요. 선택 대기 중
비밀 마법 금고 Ctrl+V 붙여넣기

여기를 클릭하고 깜빡이는 커서가 보일 때 Ctrl + V 를 누르세요!

아직 마법 주문이 들어오지 않았어요! 복사해서 붙여넣어 보세요.
미션 2 : 객체 복사

동물 친구 3마리를 모두 복사해서 잔디 놀이터에 초대하기!

글자뿐만 아니라 그림과 캐릭터도 복사할 수 있어요! 대기실의 동물 친구들을 하나씩 콕 클릭하여 선택하고 Ctrl + C, 잔디밭을 클릭하고 Ctrl + V 로 3마리 친구(토끼, 곰, 고양이)를 모두 데려오세요!

동물 캐릭터 대기실 선택 후 Ctrl+C

복사하고 싶은 동물을 클릭해서 보라색 테두리가 생기게 한 다음 Ctrl + C 를 누르세요!

🐰 마법 토끼 미션 1/3
🐻 아기 곰 미션 2/3
🐱 노랑 고양이 미션 3/3
동물을 마우스로 콕 클릭하여 선택해주세요.
잔디 놀이터 (붙여넣기 구역)
잔디밭 선택 대기 Ctrl+V 복제 구역

잔디밭 안쪽을 클릭하고 Ctrl + V 를 누르면 복사한 동물이 나타나요!

이 잔디밭을 클릭하고 Ctrl + V 로 3마리 친구를 모두 모아주세요!
초대 현황: 🐰 토끼 ✕ 🐻 곰 ✕ 🐱 고양이 ✕
목표: 세 친구 모두 초대 (0/3)
미션 3 : 글자 잘라내기

사과 바구니의 엉뚱한 수박을 잘라내어 옮기기!

사과 바구니에 들어간 '수박 🍉' 글씨를 마우스로 드래그하고 가위 단축키 Ctrl + X 로 싹둑 잘라낸 후, 수박 바구니에 Ctrl + V 로 붙여넣으세요!

사과 바구니 Ctrl+X 로 수박 잘라내기

'수박 🍉' 글자만 선택하거나 아래의 [수박 선택] 버튼을 누른 뒤 Ctrl + X 를 누르세요!

잘라내기(Ctrl+X)는 원래 자리에 있던 글자가 싹 사라져요! 선택 대기 중
수박 전용 바구니 Ctrl+V 로 붙여넣기

여기를 클릭하고 Ctrl + V 로 잘라낸 수박을 쏙 넣어주세요!

사과 바구니에서 수박을 잘라내어 이곳에 붙여넣어 보세요!
미션 4 : 마법의 타임머신

동물 농장 모두 선택하고 삭제 후 되돌리기!

농장 안을 클릭하고 Ctrl + A (전체선택) ➔ Del (삭제) ➔ Ctrl + Z (명령취소 되돌리기) 마법을 순서대로 걸어보세요!

1. 모두 선택 Ctrl+A
2. 비우기 Del
3. 되돌리기 Ctrl+Z
평화로운 행복 동물 농장 동물 6마리 거주 중
🐷 꿀꿀 돼지
🐮 얼룩 송아지
🐑 폭신 양
🐔 꼬꼬 닭
🐶 충성 멍멍이
🐴 씩씩한 말
동물들이 전부 삭제되어 우리 밖으로 사라졌어요!
Ctrl + Z (명령 취소 타임머신) 을 눌러 다시 소환하세요!
농장을 콕 클릭한 뒤 키보드의 Ctrl + A 키를 눌러 동물들을 한 번에 모두 선택해보세요!
최종 미션 5 : 화면 캡처 & 마스터 카드 발급

마스터 카드 이미지를 캡처 복사해 붙여넣고 내 이름 새기기!

윈도우즈의 화면 캡처 단축키 Win + Shift + S 또는 Print Screen (PrtScn) 키로 마스터 엠블럼을 캡처한 뒤, 카드 액자에 Ctrl + V 로 붙여넣고 이름을 적어 완성하세요!

캡처할 마스터 엠블럼 캡처 대상
